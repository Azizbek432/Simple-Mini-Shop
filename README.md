# 🛒 Simple Mini Shop

This project is a mini web application that demonstrates the cart functionality of a simple online store. Users can add products to the cart and see the total amount in real time.

---

## ✨ Features

- **Product List:** High-quality IT peripherals such as Laptops, Mice, and Keyboards.
- **Interactive Cart:** When the "+ to Cart" button is clicked, the product is instantly added to the shopping list.
- **Live Billing:** The price of each added product is immediately calculated into the `Total Price`.
- **UI/UX:** Modern, responsive, and clean design with interactive button states (hover effects and status changes).

## 📂 File Structure

- `index.html` — The main structure of the web page.
- `style.css` — Custom styling for product cards and the cart section.
- `script.js` — Business logic for adding items and calculating sums.
